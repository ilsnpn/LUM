Compiler

Sans rien installer.

LUM est écrit en C# 5 pour .NET Framework 4.8. Le compilateur est déjà fourni avec Windows : pas de Visual Studio, pas de SDK, pas de droits administrateur.

  1. Récupérez le code

    git clone https://github.com/ilsnpn/LUM.git

    Ou, sur GitHub, Code › Download ZIP.

  2. Double-cliquez sur build.bat

    Il appelle le csc.exe présent dans Windows et produit LUM.exe à côté. C’est tout.

  3. Ou avec le SDK .NET

    dotnet build

    Projet LUM.csproj, cible net48. Le code reste en C# 5 pour que build.bat continue de fonctionner.

Sous le capot

Zéro dépendance.

Uniquement des API natives de Windows, appelées directement depuis C#. Aucun paquet NuGet, aucune bibliothèque tierce.

Contribuer

Un coup de main est bienvenu.

Un bug ? Ouvrez une issue. Une amélioration ? Proposez une pull request.

Pistes pour la suite

  • Raccourcis clavier globaux pour démarrer, arrêter ou mettre en pause.
  • Le son de l’ordinateur, en plus du micro.
  • Une zone de l’écran ou une fenêtre au lieu de l’écran entier.
  • Un exe signé, pour éviter les blocages SmartScreen et AppLocker.
