Questions fréquentes

Bon à savoir.

Tout ce qu’il faut savoir avant, pendant et après votre première bulle.

Où sont enregistrées mes vidéos ?

Dans C:\Users\[USER]\Videos\LUM, le dossier Vidéos de votre session Windows. Chaque vidéo est un fichier MP4 (H.264 + AAC) nommé d’après sa date, par exemple LUM_2026-09-28_10-42-07.mp4.

Quand vous cliquez sur ■, l’Explorateur s’ouvre directement sur la vidéo. Pour y revenir plus tard : clic droit sur la bulle, puis Ouvrir le dossier des vidéos.

Et avec plusieurs écrans ?

LUM enregistre uniquement l’écran sur lequel se trouve la bulle au moment où vous cliquez sur le bouton rouge. Pendant l’enregistrement, la bulle reste sur cet écran. Les autres écrans ne sont jamais filmés : vous pouvez y garder vos notes.

Le son est-il enregistré ?

Oui, celui de votre micro : le micro par défaut de Windows, ou celui que vous choisissez par clic droit sur la bulle, puis Micro. Choisissez Pas de son pour une vidéo muette. Si aucun micro n’est disponible, la vidéo est enregistrée sans son et LUM vous prévient.

Le son de l’ordinateur (une vidéo que vous lisez, les notifications) n’est pas enregistré.

La barre de boutons apparaît-elle dans la vidéo ?

Non : votre bulle est dans la vidéo, mais pas sa barre, sur Windows 10 version 2004 ou plus récent et sur Windows 11. Sur un Windows plus ancien, la barre n’apparaît qu’au survol, et sera alors visible dans la vidéo.

Faut-il installer quelque chose ?

Non. LUM.exe est un fichier unique de 91 Ko qui se lance d’un double-clic. Il s’appuie sur .NET Framework 4.8, déjà présent dans Windows 10 et 11. Aucun droit administrateur n’est nécessaire.

Windows affiche « Windows a protégé votre ordinateur ». Que faire ?

C’est le filtre SmartScreen : il se méfie des applications récentes et peu téléchargées. Cliquez sur Informations complémentaires, puis sur Exécuter quand même. Votre navigateur peut aussi demander de confirmer le téléchargement : choisissez Conserver.

Sur un poste d’entreprise verrouillé, demandez à votre service informatique d’autoriser LUM.exe.

Ma caméra ne s’affiche pas dans la bulle.
  • Dans Paramètres Windows › Confidentialité et sécurité › Caméra, autorisez les applications de bureau à accéder à la caméra.
  • La caméra est peut-être déjà utilisée par Teams, Zoom ou une autre application : coupez-la là-bas.
  • Sur une édition « N » de Windows, installez le Media Feature Pack.

Vous avez plusieurs caméras ? Clic droit sur la bulle, puis Caméra.

Comment l’utiliser pendant une réunion Teams, Zoom ou Meet ?

Partagez votre écran entier, pas une seule fenêtre : la bulle fait alors partie de ce que les autres voient. Coupez la caméra dans l’application de visio : vous n’apparaîtrez pas en double, et certaines webcams ne se partagent pas entre deux applications.

Attention : pendant un enregistrement LUM, la bulle devient invisible pour les partages d’écran. Pour vous montrer en réunion, partagez sans enregistrer avec LUM.

Mes images sont-elles envoyées quelque part ?

Non. LUM ne se connecte jamais à internet et ne demande aucun compte. Vos vidéos sont enregistrées uniquement sur votre PC, dans C:\Users\[USER]\Videos\LUM : c’est vous qui décidez de les partager. Vos réglages (taille, position, miroir, caméra, micro) sont gardés dans %APPDATA%\LUM\settings.ini.

Comment fermer ou désinstaller LUM ?

Survolez la bulle et cliquez sur ✕, ou faites un clic droit puis Fermer LUM. Si un enregistrement est en cours, LUM termine et sauvegarde d’abord la vidéo.

Pour le désinstaller, supprimez simplement LUM.exe, et si vous voulez effacer vos réglages, le dossier %APPDATA%\LUM. Vos vidéos restent dans Videos\LUM.

LUM est-il vraiment gratuit ?

Oui. LUM est un logiciel libre, publié sous licence MIT. Son code source est public sur GitHub : tout le monde peut le lire, le compiler et l’améliorer. Voir la page Développeurs.

Et sur Mac ou Linux ?

LUM est pour l’instant réservé à Windows 10 et 11.
